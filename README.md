# Portfolio

안녕하세요. 저는 계획을 세우고 목표를 향해 하나씩 해결해 나가는 과정을 좋아하는 프로덕트 디자이너 김연수입니다.
빠른 작업 속도와 높은 집중력으로 효율적으로 진행하면서도 마지막 디테일까지 놓치지 않으며 완성도를 높이는 것을 중요하게 생각합니다.

이 포트폴리오는 **Figma에서 설계한 디자인을 실제 웹사이트로 구현하는 과정**까지 직접 경험해 보는 것을 목표로 제작했습니다.

## 🛠 Tech Stack

- **Figma** — UI/UX 디자인 및 컴포넌트 설계
- **React** — 포트폴리오 웹사이트 구현
- **HTML / CSS / JavaScript** — 화면 구성 및 스타일링
- **Git & GitHub** — 버전 관리 및 협업
- **GitHub Pages** — 포트폴리오 웹사이트 배포

## 🧩 Figma → React

Figma에서 디자인할 때 반복해서 쓰는 UI 요소를 **컴포넌트**로 만들었습니다.

React에서도 같은 구조로 컴포넌트를 구현해 디자인과 실제 웹사이트의 구조가 일치하도록 작업했습니다.
이를 통해 디자인이 화면 한 장에서 끝나지 않고, 수정과 재사용이 가능한 구조로 이어지는 흐름을 경험했습니다.

## ⚛️ React

페이지를 하나의 큰 화면으로 만들지 않고, 헤더·섹션·카드 같은 반복되는 요소를 컴포넌트 단위로 나누어 구성했습니다.

디자인(UX)과 화면 구현(프론트엔드)이 서로 영향을 덜 주고 각자 수정될 수 있도록 구조를 분리하는 방법을 익혔습니다.

## 🌿 Git & GitHub

개발자와 협업하며 Git으로 작업 내용을 관리했습니다.
같은 파일을 함께 수정해 **충돌(conflict)** 이 생겼을 때 이를 해결하는 방법도 배웠습니다.

## 💬 What I learned

- 모든 것을 다 잘할 수는 없지만 **아이디어를 웹에서 동작하는 데모까지** 직접 구현해 볼 수 있다는 것을 배웠습니다.
- 빠른 피드백을 주고받으며 서비스를 끝까지 완성해 보고 싶습니다.
